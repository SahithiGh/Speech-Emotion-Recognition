Optional example recordings.
Add an entry to manifest.json only for audio you have the right to distribute, for example:
  { "id": "example-1", "title": "Short sentence", "file": "example-1.wav", "description": "What it contains",
    "source": "Where it came from", "license": "Its license" }
and put the audio file in this folder. Examples are shown as examples, never as proof of model accuracy.
